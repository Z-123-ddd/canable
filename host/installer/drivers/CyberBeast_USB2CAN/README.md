# CyberBeast_USB2CAN — 品牌化 USB CDC 串口驱动（可选）

让 CANable2-N32（`VID_16D0&PID_117E`）在 **设备管理器 / 端口(COM) 列表** 里显示为
**“CyberBeast USB2CAN (COMx)”**，而不是系统默认的 “USB Serial Device”。

## 为什么需要它 / 为什么可选
设备是标准 USB CDC-ACM（`bDeviceClass=0x02 / SubClass=0x02`）。Windows 10/11 内置的
`usbser.inf` 已通过通用兼容 ID `USB\Class_02&SubClass_02` **自动装上 `usbser.sys` 并分配 COM 口**
——所以**不装本驱动也能正常当 CAN 用**，只是名字叫 “USB Serial Device”。本驱动只做**改名**
（用 `USB\VID_16D0&PID_117E` 这个更具体的匹配，优先级高于通用 usbser.inf）。

## 文件
| 文件 | 说明 |
|---|---|
| `CyberBeast_USB2CAN.inf` | CDC 串口 INF（复用系统 `mdmcpq.inf` + `usbser.sys`，无自带 .sys） |
| `CyberBeast_USB2CAN.cat` | 目录签名（CatalogFile） |
| `CyberBeast_USB2CAN.cer` | 对 `.cat` 签名的**自签名**证书公钥（安装时需装入本机受信任存储） |

> `.inf` 与 `.cat` 由 **libwdi**（Pete Batard，LGPL）生成模板，勿手改——改了会破坏 `.cat` 签名。
> 若要换名字/厂商，需用 libwdi 重新生成并重签。

## 安装（需管理员）
```
certutil -addstore -f Root            CyberBeast_USB2CAN.cer
certutil -addstore -f TrustedPublisher CyberBeast_USB2CAN.cer
pnputil /add-driver "CyberBeast_USB2CAN.inf" /install
```
安装程序里对应可选组件 **“品牌串口驱动 (CyberBeast USB2CAN)”**，未勾选时可运行开始菜单里的
`install_cdc_driver.bat` 手动安装。

**原理**：x64 Windows 要求驱动包目录（`.cat`）有可校验的签名。这里用自签名证书，
故必须先把公钥证书装进「受信任的根证书颁发机构 + 受信任的发布者」两处，`pnputil` 才会接受。
这正是 Zadig / libwdi 的标准做法。安装时会弹出一次“是否信任此发布者”的确认。

## 卸载
```
pnputil /delete-driver CyberBeast_USB2CAN.inf /uninstall /force
certutil -delstore Root            "USB\VID_16D0&PID_117E (libwdi autogenerated)"
certutil -delstore TrustedPublisher "USB\VID_16D0&PID_117E (libwdi autogenerated)"
```
